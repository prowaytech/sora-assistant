Privacy Policy

Last updated: 17 November 2026

Sora Assistant is a private tool used only by its owner. It is not available to the public.

Data accessed

With the owner's explicit consent, the app accesses the owner's own Google account data (Gmail, Google Calendar, Google Drive and Google Sheets) only to carry out tasks the owner requests.

Storage and sharing

Data is processed by the owner's personal assistant software running on the owner's own computer, which may send the content needed for a requested task to the AI model provider it uses. Data is not sold, not used for advertising, and not shared with anyone else.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at https://myaccount.google.com/permissions.
